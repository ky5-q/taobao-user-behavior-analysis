# 淘宝用户行为数据分析

基于阿里天池 UserBehavior 公开数据集（10 万条用户行为记录，2017-11-25 ~ 12-03 共 9 天观测窗口）的电商用户行为分析项目，覆盖 **ETL → 转化漏斗 → 留存分析 → RFM 用户分层** 的完整数据分析流程。

## 技术栈

- **数据存储与查询**：MySQL（建库建表、入库、取数）
- **数据处理**：Python / pandas（清洗、聚合、指标计算）
- **可视化**：matplotlib
- **流程**：CSV → pandas 清洗 → MySQL → SQL 取数 → 分析报告

## 核心发现

### 1. 转化漏斗：流失定位与可执行建议

- 浏览→兴趣→购买：980 → 841 → 671 人（整体转化率 68.5%）
- 按相对流失率与绝对流失人数双重标准，**"兴趣→购买"为流失最严重环节**（20.2%）
- 识别 196 名加购弃购用户（27.1%），提出购物车挽回策略（降价提醒/限时优惠券）
- 口径声明：样本仅含有行为用户，整体转化率不可与真实电商（1~3%）直接对比

### 2. 留存分析：运营日历效应发现

- 11-25 队列（n=663）次日留存 79.2%，day1-day6 仅缓降 4pp，曲线几乎不衰减（受样本口径约束）
- **day7 留存率 98.0% 异常反超 day1**——结合每日行为结构验证（浏览 UV +33%、加购 UV +36% 全行为同步上涨），判定为平台活动日（双 12 预热期）效应而非粘性变化
- 队列差异检验：11-26 队列 day1 留存 61.6% vs 11-25 的 79.2%，置信区间互不重叠，差异大概率真实

### 3. RFM 用户分层：模型局限识别

- 8 类人群画像 + 差异化运营策略（重要价值 383 人 / 重要发展 279 人 / 一般发展 198 人等）
- 识别 **R 维度塌缩**（98.2% 用户 R=0，窗口末日恰为大促日），指出模型会系统性抹掉"日常高活跃、购买力强但活动日缺席"的重要保持客户
- 提出三条改进：分位数分档（rank 破并列 + qcut）、基准日前移（活动前窗口定义 R）、F×M 降维

## 数据质量说明

- 样本为**记录级随机抽样**（10 万行 / 全量 1 亿行），高活跃用户被过度代表，各指标不可与真实电商直接对比
- 数据窗口外存在 7 个离群用户（首次行为早于窗口 1-2 个月），分析中已标注口径
- 留存指标受右截断影响（窗口末日队列无次日数据，已剔除）
